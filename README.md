# Coral network robustness and connectivity

The git repository contains the processing and analysis script for Abott et al.

The files are arranged as follows:
- `GBR_scripts`: All python script associated with creating the particle tracking data from generating starting location to creating the connectivity matrix
- `analysis`: All python and R scripts for plotting and analysing the data shown in the paper

`requirements.txt` contains the information needed to set up a python virtual environment for the analysis scripts
`parcels_req.txt` contains the same for the ocean parcels traking virtual environment
